# القاسم للدهانات والعدد – موقع + تطبيق PWA

## الملفات
- `index.html` `style.css` `script.js` : الموقع
- `site-data-loader.js` `site-data.json` : تحميل بيانات الأقسام والأسعار والعروض
- `admin.html` `admin.js` : لوحة التحكم
- `service-worker.js` `manifest.json` `apple-touch-icon.png` : التطبيق والعمل بدون إنترنت
- `robots.txt` `sitemap.xml` : محركات البحث
- `assets/images` : صور الموقع والأيقونات | `assets/uploads` : صور المنتجات المرفوعة من لوحة التحكم | `assets/video` : فيديو البداية

## بعد الرفع على GitHub Pages
استبدل `__SITE_URL__` (بدون / في الآخر) برابط الموقع الكامل، مثل `https://USERNAME.github.io/REPO`، في الملفات: `index.html` و`sitemap.xml` و`robots.txt`.
أي تعديل على الملفات الثابتة يحتاج رفع نسخة جديدة من `service-worker.js` (غيّر رقم `V`) ليتحدث التطبيق عند العملاء.

## لوحة التحكم (admin.html)
- **المنتجات:** اختر القسم والقسم الفرعي، ثم أضف/عدّل/أخفِ أي منتج.
- **الأنواع:** داخل المنتج، كل نوع له صورة ووصف وسعر (يظهر للعميل في مربعات زرقاء مرقمة).
- **الملحقات:** صور وأسعار تظهر تحت المنتج (أو تحت نوع محدد).
- **كميات منفصلة لكل وحدة:** لمنتجات مثل الأسمنت (شيكارة وكيلو).
- **الصور:** ارفع صورة (تحتاج ربط GitHub)، أو الصق رابط صورة.
- بعد التعديل اضغط «حفظ ونشر».

## ملاحظات الواجهة الجديدة
- المنتجات المميزة (الصفحة الرئيسية): من لوحة التحكم فعّل «منتج مميز» على أي منتج.
- البحث يعمل داخل الموقع بدون إنترنت. وزر «تلوين فوري» يفتح واتساب برسالة جاهزة.
